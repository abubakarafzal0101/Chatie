# Chatie - Real-Time Chat Application 💬

A modern real-time chat application built with the MERN Stack and Socket.io that enables instant communication between users.

Chatie demonstrates practical experience in building real-time web applications, including socket-based communication, frontend-backend integration, and full-stack deployment.

# 📌 Project Overview

Chatie is a full-stack real-time messaging application designed to understand how modern chat platforms work.

The application uses Socket.io for instant communication between connected users without requiring page refreshes.

This project focuses on:

- Real-time communication
- Client-server event handling
- Interactive user interfaces
- Full-stack architecture
- Modern web development practices
